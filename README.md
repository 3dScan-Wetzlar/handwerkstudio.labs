# DE-Text-Notizen und kostenlose Werkzeuge

Kostenlose Werkzeuge für deutschsprachige Textverarbeitung, plus kurze Notizen aus der Praxis.
Alles läuft im Browser: kein Upload, keine Anmeldung, keine Tracker.

Website: https://labs.handwerkstudio.de/

## Werkzeuge

- [Abkürzungen ausschreiben](https://labs.handwerkstudio.de/werkzeug/abkuerzungen-ausschreiben/) . Schreibt deutsche Abkürzungen wie z.B., d.h., u.a., i.d.R. automatisch aus. Nützlich für Vorlese-Software, Barrierefreiheit und saubere Weiterverarbeitung.
- [Lesbarkeit prüfen](https://labs.handwerkstudio.de/werkzeug/lesbarkeit-pruefen/) . Berechnet den Flesch-Reading-Ease für deutsche Texte nach der Amstad-Formel und stuft das Ergebnis ein. Kostenlos, sofort, ohne Anmeldung.
- [Text normalisieren](https://labs.handwerkstudio.de/werkzeug/text-normalisieren/) . Bereinigt deutschen Text für die Weiterverarbeitung: Abkürzungen ausschreiben, Mehrfach-Leerzeichen und überflüssige Umbrüche entfernen.

Nachschlagen: [Verzeichnis deutscher Abkürzungen](https://labs.handwerkstudio.de/abkuerzungsverzeichnis/)
